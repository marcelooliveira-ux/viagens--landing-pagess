# TripMe — landing page de agência de viagens

Landing page responsiva de uma agência de viagens fictícia, construída com HTML5 e CSS3. Projeto de certificação da formação em desenvolvimento web do SENAI RN.

**Site no ar:** https://marcelooliveira-ux.github.io/viagens--landing-pagess/

## O que a página tem

Banner de abertura com chamada principal e botão de ação, três seções de conteúdo (Minha Viagem, Nos Encontre e Conselhos) e um menu fixo no topo que navega por âncoras, com link de retorno ao início em cada seção.

O foco do projeto foi estrutura semântica, hierarquia visual e adaptação a diferentes tamanhos de tela.

## Stack

HTML5 · CSS3

Sem dependências e sem JavaScript. Publicado com GitHub Pages.

## Estrutura

```
index.html   marcação da página e seções
style.css    estilos, layout e regras de responsividade
```

## Como rodar localmente

```
git clone https://github.com/marcelooliveira-ux/viagens--landing-pagess.git
cd viagens--landing-pagess
```

Depois é só abrir o arquivo index.html no navegador.
